# Hikvision Resolution Scan

海康威视 **枪机主码流视频参数只读扫描** 工具。按网段批量读取分辨率等配置，**绝不改写设备**。

[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg?style=flat-square)](LICENSE)

---

## 安全承诺

| 约束 | 说明 |
|------|------|
| 只读 | 全程仅 `GET`，代码层禁止 `PUT` / `POST` / `DELETE` / `PATCH` |
| 保守 | 默认先探测 TCP 端口，再发 ISAPI；并发上限 16；单台超时默认 4s |
| 失败可追溯 | 不通 / 密码错 / 非海康设备 → 写入日志，可单独导出失败列表 |

读取的接口（示例）：

```text
GET /ISAPI/System/deviceInfo
GET /ISAPI/Streaming/channels/101
```

对应网页「配置 → 视音频 → 视频参数 → 主码流」中的当前生效参数。

---

## 能读到什么

与页面字段对应：

- 码流类型、视频类型（视频流 / 复合流）
- 分辨率、码率类型、图像质量
- 视频帧率、码率上限、平均码率
- 视频编码、编码复杂度、超级智能编码
- I 帧间隔、码流平滑
- 预计存储（按码率估算，供参考）

## 使用

需要本机已安装 Python 3.10+（仅用标准库，无第三方依赖）。

```text
双击「打开分辨率扫描.bat」
```

或：

```bash
python scan_gui.py
```

1. 填统一 **用户名 / 密码**（各枪相同）
2. 填网段，例如：
   - `192.168.22.1-254`
   - `192.168.22.0/24`
   - 单个 IP：`192.168.22.133`
3. 建议保持「先探测端口」勾选，并发不要开太大（默认 6）
4. 点 **开始只读扫描**
5. **导出 CSV** / **保存失败日志**
